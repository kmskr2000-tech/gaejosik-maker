# 보고서 브레인 작동 방식

혁신정책담당관실 혁신팀장의 기획보고서 작성 방식을 학습한 「보고서 브레인」과, 그 브레인으로 보고서를 쓰는 스킬의 구성과 사용법이다. 기준일 2026-10-22, 브레인 v0.2.

## 1. 구성

| 구성 요소 | 위치 | 하는 일 |
|---|---|---|
| 코퍼스 | Google Drive `NTS_보고서_코퍼스` | 과거 보고서 원문. 유형별 폴더 01~09, 서식견본 00 |
| 보고서 브레인 | Google Drive `NTS_보고서_브레인` | 원문에서 뽑은 작성 방식. 문서 노트, 렌즈, 페르소나, 충돌 규칙, 맥락 |
| `nts-planning-report` 스킬 | claude.ai 스킬 | 브레인을 읽고 보고서를 쓴다 |
| `report-brain-learn` 스킬 | claude.ai 스킬 | 새 문서를 브레인에 학습시킨다 |
| kordoc | 개인 PC (`npx -y kordoc setup`) | HWP 읽기, HWPX 생성, 공문서 검수 |
| 주간 맥락 갱신 | claude.ai 예약된 작업 (매주 월 07:47) | 지난 7일 대통령·청장 발언과 이슈를 맥락 로그로 쌓는다 |

브레인은 내부 문서에서 뽑은 내용이라 Drive에만 둔다. git 저장소에는 스킬 코드만 있다.

## 2. 브레인 안

| 폴더·문서 | 내용 |
|---|---|
| `_index` | 모든 브레인 문서의 ID 목록과 현재 버전. 스킬은 항상 이것부터 읽는다 |
| `synthesis/보고서브레인` | 페르소나: 세계관 13개, 판단 프로세스 0~8단계, 유형별 뼈대, 문체 규칙, 하지 않는 것 |
| `synthesis/versions/vX.Y` | 버전별 불변 스냅샷. 작성 스킬은 스냅샷만 따른다 |
| `synthesis/conflict-rules` | 소스끼리 갈릴 때의 해소 규칙 CR-01~CR-12 |
| `synthesis/absorb/` | 흡수 기록. 무엇을 배워 무엇이 바뀌었나 |
| `synthesis/reading-log` | 학습한 문서와 미학습 문서 목록 |
| `docs/` | 문서 노트 27개, 교차 노트 2개. 문서별 구조·제목 패턴·문장틀·판단 순간 |
| `lenses/` | 렌즈 3개: 상급기관(지침·평가 요구), 청장(키워드·서사), 국실(자료 모양·결함) |
| `context/` | `context-current`(기준 스냅샷) + `context-log-YYYYMMDD`(날짜별 발언 로그) |

## 3. 보고서를 쓸 때 (nts-planning-report)

호출: "업무보고 써줘", "원페이퍼로 정리해줘", "국실 자료 엮어서 운영방안 초안", "이 문장 워딩 수정" 등.

1. **브레인 읽기**: `_index` → 현재 버전 스냅샷 → 충돌 규칙. 브레인을 못 읽으면 쓰지 않고 멈춘다.
2. **과업 식별**: 문서 유형, 목적, 보고 대상, 분량, 마감.
3. **맥락 스캔**: `context-current`, 최근 4주 맥락 로그, 상급기관·청장 렌즈를 읽는다. 최근 2~4주 웹 검색은 필수다. 새로 찾은 발언은 맥락 로그로 저장한다. 강조 포인트 3~5줄을 먼저 보여 준다.
4. **근거 노트 고르기**: 같은 유형 최신 최종본 1~2개, 같은 주제 1개. 전 정부 문서는 양식만, 중간본은 구조만 쓴다.
5. **1차 자료 정리와 꼭지 설계**: 국실 파일은 kordoc으로 읽는다. 국실 자료를 표로 펼치고, 수치 기준일·범위를 대조하고, 과제 축으로 재분류한다. 꼭지 구조를 보여 주고 확인받는다("바로 써줘"면 생략).
6. **작성**: 스냅샷의 문체 규칙과 근거 노트의 문장틀로 쓴다. 없는 수치는 "( )".
7. **교정**: kordoc 검수 + 브레인 점검 목록.
8. **출력**: 기본 HWPX. 머리에 `brain: vX`와 적용 규칙, 끝에 참고 노트·자료 요청·판단 필요·확인한 최신 발언.

## 4. 브레인을 키울 때 (report-brain-learn)

| 하고 싶은 일 | 말하는 법 | 일어나는 일 |
|---|---|---|
| 새 보고서 학습 | 코퍼스 폴더에 올리고 "브레인에 넣어" | 문서 노트 작성 → 렌즈 보강 → 흡수 기록 → 판단 방식이 바뀌면 버전 업 |
| 청장 말씀·지침 반영 | 내용을 붙여 넣고 "맥락 갱신해" | 맥락 로그 추가 |
| 맥락 정리 | "맥락 정리해" (로그 4개 이상 쌓이면 권장) | 로그를 합쳐 `context-current`를 새로 쓴다 |
| 내가 고친 결과 반영 | 고친 전후를 주고 "피드백 반영해" | 같은 수정이 두 번 이상이면 규칙으로 올린다 |
| 전체 재합성 | "브레인 재합성" (흡수 10건마다 권장) | 흡수 기록 전부로 페르소나를 처음부터 다시 쓴다 |

파일 형식: PDF가 가장 안정적이다. HWP는 50KB~5MB만 읽힌다. DRM 파일과 대외비 표시 문서는 학습하지 않는다.

## 5. 주간 자동 갱신

- claude.ai 예약된 작업 「보고서 브레인 주간 맥락 갱신」, 매주 월요일 07:47.
- 지난 7일 국무회의·대통령 지시, 국조실·기재부 발표, 국세청 보도자료·청장 발언, 국세청 관련 언론 이슈를 검색한다.
- 새 발언이 있으면 맥락 로그 1개를 만든다. 다른 브레인 문서는 고치지 않는다.
- 요약에 "맥락 정리 권장"이 뜨면 학습 스킬로 정리한다.

## 6. 현재 한계 (v0.2)

- 미학습: 2025 신년사, 2024 하반기 관서장회의 인사말, 2024 청년정책 최종본. PDF로 올리면 학습 가능.
- 제외: 2차 업무보고 작성지침(대외비). 업무보고를 쓸 때 지침 대조가 필요하면 항목 목록을 직접 알려 줘야 한다.
- 국실 렌즈는 6개 국실 회신 기준이다. 조사국 등 사업국 회신 원형은 아직 없다.
- 서식견본 폴더가 비어 있어 HWPX는 kordoc 기본 서식(국세청 기관 서식)으로 나온다. 실제 결재 양식 HWPX를 `00_서식견본`에 올리면 그 서식을 쓴다.

## 7. 보안

- 코퍼스와 브레인은 작업할 때 Claude로 전송된다.
- 대외비 표시 문서는 올리지 않는다. 납세자 정보·직원 인적사항은 지운 뒤 올린다.
- 브레인 노트·렌즈에는 개인 실명·연락처를 넣지 않는다(공개 기관장 제외).
- 결과물을 사무실로 옮기는 경로(메일, USB)는 사내 보안 규정을 따른다.

```
이 프로젝트는 국세청 혁신정책담당관실 혁신팀장의 기획보고서 작업 공간이다. 사용자는 국실 1차 자료를 엮어 대통령 업무보고, 국세행정 운영방안, 정부업무평가 대응, 범부처 과제 발굴, 수시 기획보고, 원페이퍼, 회의·말씀자료를 만든다.

[항상 쓰는 스킬]
- 보고서를 쓰거나 고치거나 엮는 요청 → nts-planning-report
- 새 보고서 학습, 맥락 갱신·정리, 피드백 반영, 재합성 → report-brain-learn
- 보고서라는 말이 없어도 국세청 기획 문서 작업이면 위 스킬을 먼저 불러라.

[브레인]
- 작성 방식의 기준은 Google Drive 「NTS_보고서_브레인」이다. 루트의 _index를 먼저 읽고, 거기 적힌 현재 버전 스냅샷을 따른다.
- 브레인을 읽지 못하면 일반 문체로 대신 쓰지 말고 멈춰서 알려라.
- 과거 보고서 원문은 「NTS_보고서_코퍼스」에 있다. 노트로 부족할 때만 연다.

[최신 맥락]
- 보고서마다 최근 2~4주 대통령 발언, 국세청 보도자료·청장 발언, 관련 언론 이슈를 반드시 검색하라.
- 새로 찾은 발언은 브레인 context 폴더에 context-log-YYYYMMDD로 저장하라.
- 내가 붙여 넣은 자료가 검색 결과보다 우선이다.

[작성 원칙]
- 1차 자료에 없는 사실·수치·사례를 만들지 마라. 모르는 수치는 "( )"로 비우고 자료 요청 목록에 올려라.
- 상위 메시지에 맞추려고 과제 내용을 다른 것처럼 포장하지 마라.
- 전 정부·전임 청장의 슬로건은 쓰지 마라.
- 꼭지 구조는 쓰기 전에 보여 주고 확인받아라. 내가 "바로 써줘"라고 하면 생략하라.
- 결과물 머리에 brain 버전과 적용한 충돌 규칙을, 끝에 참고 노트·자료 요청·판단 필요·확인한 최신 발언을 붙여라.

[출력]
- 기본은 kordoc으로 만든 HWPX다. kordoc을 쓸 수 없으면 개조식 텍스트로 내고 그 사실을 알려라.
- 짧은 워딩 수정은 텍스트로 답해라.

[보안]
- 대외비 표시 자료, 납세자 정보, 직원 인적사항은 결과물과 브레인에 옮기지 마라. 발견하면 알려라.
- 답은 한국어로 하라.
```
