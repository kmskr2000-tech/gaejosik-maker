# 제출 전 교정 체크리스트

5단계에서 항목별로 점검한다. 걸리는 항목은 고치거나, 고칠 수 없으면 출력 끝 "판단 필요 지점"에 적는다.

## A. 상위 메시지 정합

- [ ] 2단계에서 정한 강조 포인트 3~5개가 각각 최소 한 꼭지에 들어갔는가
- [ ] 꼭지 제목에 상위 키워드가 원문 표현 그대로 들어갔는가(유사어로 바꾸지 않았는가)
- [ ] 상위 기조와 반대 방향의 문장이 없는가(예: 조사 완화 기조에서 "조사 확대")
- [ ] 국정과제 연계 표시가 필요한 유형(업무보고, 과제 발굴)에서 빠진 과제가 없는가

## B. 사실·수치

- [ ] 모든 수치에 출처(국실 자료, 보도자료, 통계)가 있는가
- [ ] 같은 수치가 문서 안에서 두 번 이상 나올 때 값이 일치하는가
- [ ] 비워 둔 "( )"가 자료 요청 목록에 모두 올라갔는가
- [ ] 시점 표기('25년, '26.上 등)가 일관되는가
- [ ] 법령명이 「」로 정확히 표기됐는가

## C. 구조·논리

- [ ] 각 꼭지 첫 문장이 "왜"를 담고 있는가(국실 자료 그대로 "무엇"만 있지 않은가)
- [ ] 국실 간 중복 과제가 하나로 합쳐졌는가
- [ ] 같은 위계의 항목이 같은 문법 구조인가
- [ ] 꼭지당 ○ 항목 수가 2~4개 범위인가
- [ ] 분량이 지시 범위 안인가

## D. 표현

- [ ] 종결이 명사형·"~ 추진" 형식인가. "~한다"가 섞이지 않았는가
- [ ] 과장 표현(완전, 전면, 100%, 세계 최초)이 없는가
- [ ] 상위 기관 독자가 모르는 세무 용어가 풀이 없이 나오지 않는가
- [ ] 전 정부·전임 청장 슬로건이 남아 있지 않은가
- [ ] 코퍼스 문체와 다른 "일반 문장"이 섞이지 않았는가

## E. 리스크

- [ ] 국회·언론이 공격할 수 있는 문장이 있는가. 있으면 방어 논리를 붙였는가
- [ ] 타 부처 소관을 국세청 성과처럼 쓴 곳이 없는가
- [ ] 대외비·개인정보가 1차 자료에서 그대로 넘어오지 않았는가
- [ ] 아직 결정 안 된 사항을 확정처럼 쓰지 않았는가

## F. 출력

- [ ] 사용자가 요청한 형식(텍스트, docx)으로 냈는가
- [ ] 자료 요청 목록과 판단 필요 지점을 끝에 붙였는가
