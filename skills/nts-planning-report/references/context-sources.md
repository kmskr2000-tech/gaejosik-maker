# 실시간 맥락 수집 소스와 방법

이 파일은 2단계(맥락 스캔)에서 쓴다. 웹 검색이 가능한 환경에서는 아래 소스를 검색하고, 불가능하면 사용자에게 해당 소스의 내용을 붙여 달라고 한다. 결과는 브레인의 `context/context-current` 문서에 반영해 두면 다음 작업에서 재사용된다.

## 우선순위

높은 순서대로. 상충하면 위가 이긴다.

1. 대통령 직접 발언·지시
2. 국정과제·국정기조 공식 문서
3. 국무조정실·기획재정부 작성 지침
4. 국세청장 메시지
5. 사회 이슈·언론

이유: 보고서는 결국 위로 올라간다. 아래 소스의 표현이 위 소스와 다르면 위 소스의 표현으로 통일해야 읽는 쪽에서 어색하지 않다.

## 소스별 접근

| 소스 | 어디서 | 검색어 예 | 확인 주기 |
|---|---|---|---|
| 국무회의 모두발언·지시사항 | 대통령실 홈페이지 브리핑, 정책브리핑(korea.kr) "국무회의" | `국무회의 모두발언 세정`, `대통령 국무회의 지시 ○월` | 매주 |
| 수석보좌관회의·현장 발언 | 대통령실 브리핑, 주요 언론 | `대통령 수석보좌관회의 발언`, `대통령 현장 세금` | 매주 |
| 국정과제 | 국정기획위원회 발표 자료, 정책브리핑 | `국정과제 국세청`, `국정과제 조세 공정` | 분기 |
| 정부업무평가 지침 | 국무조정실 정부업무평가위원회(evaluation.go.kr) | `정부업무평가 시행계획 ○○년` | 연초·평가 시즌 |
| 업무보고 작성 지침 | 공문(사용자 제공) | 해당 없음 | 지시 시 |
| 국세청 보도자료 | 국세청 홈페이지(nts.go.kr) 보도자료 | `국세청 보도자료 ○월` | 매주 |
| 국세청장 메시지 | 취임사, 전국 세무관서장 회의, 간부회의 말씀자료(내부), 청장 SNS | `국세청장 세무관서장 회의`, `국세청장 취임사` | 매주 |
| 사회 이슈 | 주요 일간지·경제지, 조세 전문지(조세일보, 세정일보, 택스워치 등) | `국세청 논란`, `세무조사 여론`, `국회 기재위 국세청 지적` | 매주 |

청장 SNS와 내부 말씀자료는 검색으로 잡히지 않는다. 사용자가 복사해 붙이거나 브레인의 `context/context-current` 문서에 직접 적어 두는 것을 전제로 한다.

## 수집 결과 정리 형식

검색이나 사용자 자료에서 뽑은 내용은 아래 형식으로 브레인의 `context/context-current` 문서에 추가한다. 원문 표현을 그대로 보존하는 것이 중요하다. 보고서에서 그 표현을 재사용하기 때문이다.

```
### [날짜] [소스] [화자]
- 원문 표현: "..."
- 국세청 연결 포인트: ...
- 반영 우선순위: 상 / 중 / 하
```

## 판단 기준: 무엇을 강조할 것인가

맥락 스캔의 목적은 "지금 이 문서에서 앞세울 메시지 3~5개"를 고르는 것이다. 고를 때 기준:

- 최근 2~4주 안에 대통령 또는 청장이 2회 이상 반복한 표현은 반드시 넣는다. 반복은 강조 신호다.
- 국세청이 직접 수단을 가진 주제를 우선한다. 국세청이 할 수 없는 일(세법 개정 자체 등)은 "협조·건의"로 내린다.
- 사회 이슈가 국세청에 불리한 방향(세무조사 논란, 체납 관리 부실 지적 등)이면 방어 논리를 꼭지 하나로 둔다. 모른 척하면 질문이 들어온다.
- 전년 문서와 같은 키워드가 올해 상위 메시지에서 사라졌으면 비중을 줄인다. 상위 기관이 더 이상 안 쓰는 말을 국세청만 쓰고 있으면 낡아 보인다.

## 주의

- 언론 기사 한 건으로 "강조사항"을 단정하지 않는다. 공식 브리핑이나 반복 발언으로 확인한다.
- 검색 결과의 날짜를 반드시 본다. 전임 청장이나 전 정부 자료가 섞여 나온다.
- 검색이 안 되는 환경에서 추측으로 "최근 강조사항"을 쓰지 않는다. 모르면 사용자에게 묻는다.
