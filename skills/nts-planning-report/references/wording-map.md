# 워딩 번역표

국실 1차 자료의 표현(실무 언어)을 상위 메시지 표현(국정 언어)으로 바꾸는 표다. 4단계 작성에서 쓴다.

원칙 두 가지.

- 실제 내용이 뒷받침되는 범위에서만 올린다. "전산 개선"을 "AI 대전환"으로 쓰려면 실제로 AI 요소가 있어야 한다. 없으면 "디지털 기반 ○○ 개선"까지만.
- 상위 기관이 최근 쓰는 표현을 그대로 가져온다. 비슷한 말로 바꾸지 않는다. "국민 체감"을 "국민 만족"으로 바꾸면 연결이 끊긴다.

## 국정기조 키워드 ↔ 국세청 표현

| 상위 표현 | 국실 자료에서 흔한 표현 | 보고서 표현 |
|---|---|---|
| AI 대전환 | 전산 고도화, 시스템 개선, 자동화 | AI 기반 ○○ 전환, AI 활용 ○○ 고도화 |
| 국민 체감 | 서비스 개선, 편의 제공 | 납세자 체감 ○○, 국민이 체감하는 ○○ |
| 민생 회복 | 소상공인 지원, 영세 사업자 배려 | 민생 안정을 위한 세정 지원, 소상공인·자영업자 세부담 완화 |
| 조세정의·공정 | 탈세 대응, 조사 강화 | 조세정의 확립, 공정 과세 기반 강화, 역외·지능형 탈세 엄정 대응 |
| 재정 수입 확보 | 세수 관리, 징수 | 안정적 세입 기반 확충, 성실신고 지원을 통한 자발적 납세 |
| 통합 재정수입기관(KRS) | 국세외수입 징수 위탁 | 국가 재정수입 통합 관리 체계 구축 |
| 실용 | 효율화, 비용 절감 | 성과 중심 ○○, 현장 중심 ○○ |
| 규제 혁신 | 절차 간소화, 서식 폐지 | 납세 협력 비용 절감, 불필요한 절차 정비 |
| 정부혁신·적극행정 | 업무 개선, 우수 사례 | 적극행정을 통한 ○○, 일하는 방식 혁신 |

이 표는 `context-current.md`의 키워드와 맞물려야 한다. 키워드가 바뀌면 이 표도 손본다.

## 톤 조정 패턴

| 국실 자료 톤 | 문제 | 바꾸는 방법 |
|---|---|---|
| "~를 철저히 하겠음" | 의지 표명만 있고 수단이 없음 | 수단을 앞에 붙인다. "○○ 시스템 도입으로 ~ 관리 강화" |
| "○○ 시스템 구축 완료" | 국민 효과가 안 보임 | 결과로 바꾼다. "○○ 시스템 구축으로 △△만 명 △△ 절차 생략" |
| "타 부처 협조 필요" | 책임 전가로 읽힘 | "○○부와 협업하여 ~ 추진"으로 능동형 |
| "검토 중" | 평가에서 실적 인정 안 됨 | 시점을 붙인다. "'26.下 시행 목표로 ○○ 검토" |
| "문제 없음", "완료" | 단정, 과장 | "안정적 운영 중", "1차 완료 후 고도화 추진" |
| 세무 전문 용어 나열 | 상위 기관 독자가 못 읽음 | 괄호로 풀거나 효과 중심으로 바꾼다 |

## 피할 표현

- 완전 해소, 전면 차단, 원천 봉쇄, 100% : 반증 하나로 무너진다. "대폭 축소", "사전 차단 강화"로.
- 세계 최초, 유일 : 확인되기 전까지 금지.
- 강력 단속, 일벌백계 : 세무조사 완화 기조와 충돌. "엄정 대응"까지만.
- 전 정부 표현(코퍼스에서 발견되면 사용자에게 알림) : 상위 기관이 더 이상 쓰지 않는 슬로건.
