# 문서 유형별 뼈대

다섯 유형의 기본 구조다. 코퍼스에 같은 유형의 실제 문서가 있으면 그 구조를 우선하고, 이 파일은 빈칸을 메우는 데 쓴다.

## 1. 대통령 업무보고

목적: 국세청이 국정기조를 어떻게 실현하는지 1년 단위로 보고. 가장 정치적이고 가장 상위 메시지 의존도가 높다.

```
Ⅰ. 일반 현황
   □ 조직·인력·예산 (1쪽, 표)
   □ 지난 1년 주요 성과 (국정과제 연결 중심)
Ⅱ. 정책 환경과 추진 방향
   □ 대내외 여건 (세수, 경제, 국민 요구)
   □ 추진 방향 (국정기조를 국세청 언어로 번역한 3~4개 기둥)
Ⅲ. 핵심 추진 과제
   □ 기둥별 2~3개 과제. 각 과제는 "왜(상위 메시지) → 무엇을 → 언제까지 → 기대효과"
Ⅳ. 협조 필요 사항
   □ 법령 개정, 예산, 타 부처 협업
```

작성 원칙:
- Ⅱ의 기둥이 Ⅲ의 꼭지 순서를 결정한다. 기둥 설계에 시간을 가장 많이 쓴다.
- 국정과제 번호와 명칭을 과제마다 괄호로 단다. 예: (국정과제 ○○번 연계)
- 성과는 "국민이 무엇을 얻었는가"로 쓴다. "시스템 구축 완료"가 아니라 "○○만 명이 ○○ 절차 생략".
- 대통령 강조 키워드가 각 기둥 제목에 최소 1회 들어가게 한다.

## 2. 범부처 추진과제 대응 국세청 과제 발굴

목적: 국조실·기재부·대통령실이 "○○ 관련 과제를 내라"고 할 때 국세청 과제를 찾아 제출. 요구 양식이 공문에 따라오는 경우가 많다.

```
□ 과제명
 ○ 추진 배경 (범부처 과제와의 연결 1~2줄)
 ○ 추진 내용 (구체 조치, 대상, 시점)
 ○ 기대 효과 (수치 가능하면 수치)
 ○ 소관 부서·협업 부처
 ○ 소요 예산·법령 개정 필요 여부
```

작성 원칙:
- 공문에 양식이 있으면 그 양식의 항목명을 글자 그대로 쓴다. 바꾸면 취합하는 쪽에서 되돌려 보낸다.
- 국실 자료를 "범부처 과제 키워드 ↔ 국세청 기존 과제" 매핑표로 먼저 펼친다. 기존 과제를 재포장하는 것이 신규 과제 창작보다 안전하고 빠르다.
- 발굴 과제는 수 자체보다 "상위 기관이 보고서에 인용하기 좋은가"가 기준이다. 수치와 국민 체감 효과가 있는 과제를 앞에 둔다.
- 과제마다 "이미 추진 중 / 신규 / 검토 중" 상태를 표시한다.

## 3. 정부업무평가 대응자료

목적: 국조실 정부업무평가(주요정책, 규제혁신, 정부혁신, 정책소통 등 부문별 지표)에 대한 실적 서술. 평가 지표 문구에 정확히 대응해야 점수가 난다.

```
□ 지표명 (평가 지침의 문구 그대로)
 ○ 목표 (연초 계획 수치)
 ○ 추진 실적 (계획 대비 달성, 시점별)
 ○ 성과·효과 (정량 → 정성 순)
 ○ 우수 사례 (1~2건, 구체 스토리)
 ○ 미흡 사항과 보완 계획 (솔직하되 짧게)
```

작성 원칙:
- 평가 지침의 채점 기준을 먼저 읽고 기준 항목 순서대로 쓴다. 평가자는 기준표를 옆에 놓고 읽는다.
- 실적은 "계획 ○○ → 실적 ○○ (달성률 ○○%)" 구조로. 달성률이 낮으면 이유와 보완을 같이 쓴다. 숨기면 더 깎인다.
- 우수 사례는 "문제 → 조치 → 결과(수치) → 국민 반응" 네 문장 구조.
- 전년 평가에서 지적받은 사항이 있으면 개선 여부를 반드시 넣는다.

## 4. 국세행정 운영방안

목적: 연초(연간) 또는 하반기에 국세청의 한 해 세정 운영 기조와 과제를 전 직원과 외부에 제시. 전국 세무관서장 회의 자료가 된다.

```
Ⅰ. 세정 여건
   □ 세수 여건 (예산, 전년 실적, 경기)
   □ 납세 환경 변화 (디지털, 국제, 인구 등)
   □ 국정기조와 청장 방향
Ⅱ. 운영 기조 (슬로건 1개 + 기둥 3~4개)
Ⅲ. 분야별 추진 과제
   □ 세입 확보·성실신고 지원
   □ 납세서비스·디지털(AI)
   □ 조세정의·탈세 대응
   □ 조직·인사·조직문화
   (코퍼스의 실제 분야 구분을 따른다)
Ⅳ. 추진 체계·일정
```

작성 원칙:
- Ⅱ의 슬로건과 기둥은 청장 메시지에서 가져온다. 청장이 쓴 표현을 그대로 쓰는 것이 원칙이다.
- 내부 독자(직원)와 외부 독자(언론)가 모두 읽는다. 내부용 지시 어조와 외부용 성과 어조가 섞이지 않게 분야별로 톤을 정한다.
- 전년 운영방안과 비교해 무엇이 새로운지 사용자에게 표로 보여 준다. "작년과 똑같다"는 평가를 가장 경계한다.

## 5. 수시 기획보고

목적: 청장 지시, 현안 발생, 국회·언론 대응, 타 기관 요청 등으로 짧은 시간에 만드는 1~3쪽 보고. 유형이 다양하므로 아래 공통 뼈대만 두고 상황에 맞게 줄인다.

```
□ 보고 배경 (왜 지금 이 보고인가, 1~2줄)
□ 현황·문제점 (사실과 수치)
□ 검토 내용 또는 대응 방안 (대안이 있으면 대안별 장단점)
□ 향후 계획 (일정, 담당)
□ 건의 사항 (결정이 필요한 것)
```

작성 원칙:
- 첫 줄에 결론을 쓴다. 읽는 사람이 첫 줄만 읽어도 판단할 수 있어야 한다.
- 대안을 낼 때는 추천안을 표시하고 이유를 한 줄 단다.
- 분량 지시가 없으면 1쪽으로 쓰고, 근거는 붙임으로 뺀다.

## 공통: 붙임 구성

- 붙임 1: 세부 과제별 추진 계획표 (과제, 내용, 일정, 담당, 예산)
- 붙임 2: 수치 근거 (출처 명시)
- 붙임 3: 국실별 원자료 요약 (필요 시)
