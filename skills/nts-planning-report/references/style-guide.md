# 문체·기호 규칙

이 파일은 코퍼스가 없거나 코퍼스에 규칙이 명시되지 않은 부분을 보완한다. 코퍼스와 충돌하면 코퍼스가 이긴다. 사용자가 코퍼스를 분석해 이 파일을 고쳐 가는 것을 전제로 한다.

## 기호 위계

정부 보고서 개조식의 표준 4단 위계다. 코퍼스에서 실제 쓰는 기호를 확인한 뒤 맞춘다.

```
Ⅰ. 대제목 (로마숫자)
 1. 중제목 (아라비아숫자)
 □ 꼭지 (네모)
  ○ 세부 항목 (동그라미)
   - 부연 (대시)
    · 예시·수치 (가운뎃점)
    ※ 참고·주석
    * 각주
```

- 한 꼭지(□) 아래 ○는 2~4개가 적당하다. 1개면 꼭지를 합치고, 5개 이상이면 꼭지를 나눈다.
- 같은 위계의 항목은 같은 문법 구조로 쓴다. ○ 하나가 "~ 추진"이면 옆 ○도 명사형으로 끝낸다.

## 종결 형식

- 문장은 명사형 또는 "~ 추진", "~ 강화", "~ 확대", "~ 마련", "~ 시행", "~ 개선"으로 끝낸다. "~한다", "~했다", "~할 것이다"를 쓰지 않는다.
- 마침표를 찍지 않는다. 코퍼스가 찍으면 따른다.
- 한 항목은 한 줄, 길어도 두 줄 안에서 끝낸다. 세 줄이 넘으면 하위 항목으로 쪼갠다.
- 조사 생략은 의미가 살 때만 한다. "납세자 편의 제고 위해" 식의 어색한 생략은 피한다.

## 자주 쓰는 서술어와 용법

| 서술어 | 쓰는 자리 |
|---|---|
| 추진 | 새로 시작하거나 진행 중인 과제 |
| 강화 | 기존 기능을 더 세게 |
| 확대 | 범위·대상을 넓힘 |
| 고도화 | 시스템·분석 수준을 올림 |
| 마련 | 제도·기준·방안을 새로 만듦 |
| 정비 | 기존 제도를 손봄 |
| 제고 | 수준·만족도·효율을 올림 |
| 해소 | 불편·애로·사각지대를 없앰 (완전 해소는 피함) |
| 지원 | 납세자·기업을 도움 |
| 엄정 대응 / 엄단 | 탈세·불법에 대한 조치 |
| 선제적 | 문제 발생 전 대응 |
| 체감 | 국민이 느끼는 효과 (상위 메시지에서 자주 요구) |

## 숫자·단위 표기

- 숫자는 아라비아 숫자, 천 단위 쉼표. 예: 381.7조 원, 1,234건
- 증감은 전년 대비를 기본으로 하고 괄호에 표시. 예: 218.6조 원(전년 대비 +4.2조 원, 2.0%↑)
- 기간은 '25년, '26.6월, '26.上 형식. 코퍼스 확인.
- 비율은 소수 첫째 자리까지.
- 출처 없는 수치는 "( )"로 비워 둔다. 임의 수치를 넣지 않는다.

## 법령·기관·제도 표기

- 법령명은 「」. 예: 「국세기본법」, 「국세외수입 체납액의 징수 및 관리에 관한 법률」
- 처음 나오는 약칭은 괄호로 풀어 준다. 예: 통합 재정수입기관(KRS, Korea Revenue Service)
- 기관명은 공식 약칭. 기재부, 국조실, 대통령실, 국회 기재위
- 제도명은 코퍼스의 표기를 그대로. 예: 정기 세무조사 시기선택제, 미리채움·모두채움 서비스

## 괄호와 강조

- 괄호는 부연, 출처, 영문 약칭, 시점에만 쓴다.
- 굵게·밑줄은 한글 문서에서 핵심 키워드 1~2곳만. 텍스트 출력에서는 【】 또는 별도 표시 없이 두고 사용자가 한글에서 강조한다.
- 영문·외래어는 꼭 필요할 때만. "AI"는 그대로, "디지털 전환"은 한글.

## 꼭지 제목 패턴

코퍼스에서 제목 패턴을 뽑아 여기에 추가한다. 일반적인 정부 보고서 패턴:

- "[수단]으로 [목표] 실현" : AI 기반 세정 혁신으로 국민 체감 서비스 실현
- "[대상] [조치] [강화/확대]" : 고액·상습 체납자 추적 강화
- "[가치] [동사형 명사]" : 공정 과세 기반 확립
- "[시점] [과제]" : '27년 국세외수입 통합징수 시행 준비

제목 길이는 15자 안팎. 20자를 넘으면 줄인다.

## 보고 대상별 톤 차이

| 대상 | 톤 |
|---|---|
| 대통령실·국조실 | 국정기조 연결 최우선. 세무 전문 용어 최소화. 국민 체감 중심 |
| 국세청장 | 실행 가능성과 리스크를 더 적는다. 세무 용어 사용 가능 |
| 국회·언론 대비 | 방어 논리 포함. 수치 출처 명확 |
