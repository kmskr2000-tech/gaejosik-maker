# 코퍼스 폴더

과거 보고서 원문을 넣는 보조 저장소다. 코워크 프로젝트 지식에 올리는 것이 우선이고, 이 폴더는 프로젝트를 쓰지 않을 때나 문체 앵커로 쓸 대표 문서 2~3편만 둘 때 쓴다. 파일이 많아지면 스킬 로딩이 무거워진다.

## 파일명 규칙

```
YYYY-MM_유형_제목.md
```

유형 코드:

| 코드 | 유형 |
|---|---|
| 업무보고 | 대통령 업무보고 |
| 과제발굴 | 범부처 추진과제 대응 |
| 업무평가 | 정부업무평가 대응자료 |
| 운영방안 | 국세행정 운영방안 |
| 수시 | 수시 기획보고 |

예: `2026-01_운영방안_2026년 국세행정 운영방안.md`

## 변환

한글(HWP) 파일은 텍스트로 변환해 넣는다. 기호(□ ○ -)와 들여쓰기가 살아 있어야 문체 학습에 쓸 수 있다. 표는 마크다운 표로 바꾸거나 "[표: ○○]"로 표시한다.

## 보안

대외비 표시가 있는 문서, 개인정보(납세자 정보, 직원 인적사항)가 포함된 문서는 넣지 않거나 해당 부분을 지운 뒤 넣는다. 이 폴더와 프로젝트 지식의 내용은 외부 AI 서비스로 전송된다.
